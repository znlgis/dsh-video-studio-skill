# 质量门禁（方法论 G0–G8）

Agent 看不见画面、听不见声音，所以**验收必须脚本化 + 静帧目检**双轨。

> ## ⚠ 两套编号别混用
>
> 本页的 `G0–G8` 是**方法论分组**（按"查什么"分类，写给写剧本/写场景的人看）。
> `render.py` 落进 `work/gates.json` 与 `out/QC-REPORT.md` 的，是**运行时账本 id**（按"哪一步判"排）。
> 两套编号**有重名但不同义**，看到 `G0` 先确认是哪一套：
>
> | 本页（方法论） | 账本 id（运行时） | 关系 |
> |---|---|---|
> | G0 内容门禁：上屏数字可溯源 | `G0` 渲染前资源预检 | **同名不同义**：账本 G0 查字形/字体/TTS/web 页，不核对数字出处 |
> | G1 帧级门禁（确定性/单帧预算/元素存在性） | — | 人工/代码评审，不进账本 |
> | G2 静帧门禁（母版预览目检） | `signoff`（`stills` 闸） | 目检结论走人工签核 |
> | G3 音频门禁（音效/混音/母带） | `G5` 响度/真峰 | 账本只查成片级的两个数 |
> | G4 成片门禁（容器/时长/锐度/字幕/黑帧） | `G4` 容器 · `G5` 响度 · `G6` 锐度比 · `G7` 字幕条数 · `G8` 黑帧 | 账本把 G4 拆成 5 行 |
> | G7 时间层门禁（闪烁/空窗/同步） | `G9` 帧级深检 | **同名不同义**：账本 G9 才是时间层 |
> | G8 页面层门禁（web 文字重叠/出画） | web 引擎 qa_text 结果 | 只有 `--engine web` 才有 |
> | — | `G10` 词级时间戳 · `G11` VMAF/SSIM · `G12` ASR 回读 | 详见 [delivery-gates.md](delivery-gates.md) 与 [word-timeline.md](word-timeline.md) |
>
> 一句话记法：**本页 G0–G8 是"查什么"，账本 G0 + G4–G12 是"哪一行判"**。
> 账本里**没有** `G1`/`G2`/`G3`：`G0` 之后直接从 `G4` 开始（容器），人工目检走 `signoff` 的 `stills` 闸，不进 gate matrix。

## G0 内容门禁：上屏数字可溯源

| 判据 | 做法 |
|---|---|
| 每个上屏的数字/年份对得回编号 | 建 MARK 表：数字 → 出处链接 |
| 无出处不上屏 | 单独黑名单文件，写清"为什么不行、实际是什么" |
| 口径一致 | 同一数字在剧本/字幕/画面里表述完全相同 |
| 因果表述正确 | 人工复核（这类错误最容易被评论区抓） |

真实收益：75 条主张 + 25 条黑名单，抓出 8 处硬伤。

## G1 帧级门禁（渲染期）

| 判据 | 阈值 | 怎么查 |
|---|---|---|
| 确定性 | 0 处 random/time() | grep 统计 |
| 无状态 | 模块级只缓存静态几何 | 代码评审 |
| 单帧预算 | ≤ 150 ms（浏览器）/ ≤ 25 ms（PIL） | 代码里计时并打印 fps |
| 段尾停住 | 最后 2 s 两帧逐像素相同（关掉噪声后） | 断言 |
| 元素存在性 | 该有的标题/淡入都出现 | **最难，见下** |

**"元素存在性"是分水岭**：画面"能出图"时，最难发现的是"该有但没有"。字段改名（`act.t0` → `act.start`）后，全片十幕淡入与图名框静默失效，零报错。解法：改名后必须跑 `snap` 抽帧对比。

## G2 静帧门禁（每段交付前）

```bash
python -c "
import filmkit as K, scenes
from filmkit import snap
for t in (0.6, 3.0, 6.5):
    img = scenes.draw_frame(scene, t, 8.0, t, script, int(t*30))
    img.save('qa/scene_%s.png' % t)
"
```

必须检查四件事：没有空白帧、没有元素出画、字幕没被挡、构图有重心。
交付报告里要写"**已用 read_image 亲眼确认**"+ 预览文件名。这是把"agent 看不见"转成流程约束。

## G3 音频门禁

| 判据 | 阈值 |
|---|---|
| 单条音效 QC | **以 `sfxkit.qc()` 的实际判据为准**（削波 > 0、真峰 > -0.1 dBTP、直流 > 0.002、开头跳变 > 0.1、结尾残留 > 0.01、峰值 < -24 dBFS、10k 占比 > 25%、<60 Hz 占比 > 45%、频谱平坦度、机械感、包络起伏、左右相关） |
| 同 seed 双渲染 | 逐采样相同 |
| 无 NaN/Inf | 0 |
| 循环无缝 | 接缝跳变比 < 1.5 |
| 全程有声 | 每 20 s 窗口 RMS > 0.002 |
| 旁白突出 | 旁白窗 vs 间隙窗 RMS 差 ≥ 12 dB |
| 母带 | -16 ± 0.5 LUFS，真峰 ≤ -1 dBTP |

## G4 成片门禁（可复制）

```python
errors, warns = [], []
pr = K.probe(film); f = pr["format"]

# 容器
assert f["duration"] > 0
v = [s for s in pr["streams"] if s["codec_type"] == "video"][0]
# 比的是**交付规格**不是内部构图。qa_report(expect_w=, expect_h=, expect_fps=) 会从
# timeline.json 的 video 块取期望值；缺省回落 1920x1080@30。
assert (v["width"], v["height"]) == (W, H)   # W/H 这里代表交付宽高，不是 1920x1080 常量
assert any(s["codec_type"] == "audio" for s in pr["streams"]), "无音轨"

# 时长
assert abs(float(f["duration"]) - frames / FPS) < 0.5

# 响度
lo = K.loudness(film)
assert -17.5 <= lo["I"] <= -14.5, lo
# ⚠ 不要写 lo.get("TP", 0)：缺键时 0 会被当成"合格"，门禁静默失效
assert "TP" in lo, "真峰没测到（ebur128 需要 peak=true）: %s" % lo
assert lo["TP"] <= -1.0, lo

# 锐度比（编码损失）——比码率下限可靠
# ⚠ ref 必须是场景函数在 t=dur*0.3 重新渲染的原图；用成片自己抽帧会让 ratio 恒 ≈ 1.0
ref = draw_frame(scene_at(dur * 0.3), ...)          # 或 render.py 的 st_qa 传 ref_img=
q = K.encode_quality(film, None, at_sec=dur * 0.3, ref_img=ref)
assert q["ratio"] >= 0.85, q

# 字幕条数 = 剧本句数（查"静默丢字幕"）
assert K.write_srt(tl["scenes"], tmp_srt) == len(script["lines"])

# 黑帧（首尾之外）
assert K.detect_black(film) == 0
```

## G5 完整性与一致性

| 判据 | 做法 |

## 编码质量门禁的实测依据

同一画面、三种导出方式（本机实测，1080p30，90 帧，payload 为渐变+卡片+文字）：

| 方式 | 耗时 | 速度 | 结论 |
|---|---|---|---|
| PIL → rawvideo 管道 → libx264 | 0.89 s | **100 fps** | 推荐 |
| PIL → cv2.VideoWriter(mp4v) → 重编码 | 1.71 s | 52 fps | 二次有损，慢一倍 |
| PIL → PNG image2pipe → libx264 | 2.76 s | 33 fps | PNG 编码开销大 |

默认走 rawvideo 直通；PNG 只在需要无损中间件时用。

## 码率不是质量指标

暗色简洁内容用 CRF18 出来只有 0.5–1 Mbps，这是正常的——x264 在低细节区域不需要更多比特。真实项目里踩过的坑：一条 1080p30 科普片用 `cv2.VideoWriter` 中间层 + CRF19 重编码，成片 1.1 Mbps，文字明显发软。

**用"锐度比"替代码率下限**：

```python
q = K.encode_quality("out/film.mp4", "work/qa/snap.png", at_sec=12.0)
# {'sharp_ref': 1204.0, 'sharp_dec': 1120.3, 'ratio': 0.9305}
```

- ratio ≥ 0.92：好
- 0.85–0.92：可接受（文字可能略软）
- < 0.85：**必须降 CRF 或提 preset**

# 时间层门禁（G7）与页面层门禁（G8）

> G0–G6 都是"某一帧/某一条音效"层面的检查。**时间层检查的是"看完全片才能发现的问题"**：
> 单看任何一帧都正常，整片看下来却"一帧白闪过去了""这段没东西看""这一下没有声音"。

## G7 时间层门禁（`qa_frames.py`）

```bash
python qa_frames.py out/film.mp4 --cues work/cues.json \
       --out work/qa/deep.json --png work/qa/deep.png
```

| 判据 | 阈值 | 报告字段 | 失败说明 |
|---|---|---|---|
| 单帧闪烁 | 0 条 | `flicker[]` | 只亮一帧、前后帧都正常（`bbox` 指出位置） |
| 画面空窗 | 首尾外 0 段 | `black_windows[]` | ≥0.8 s 平均亮度极低 |
| 音画同步 | `\|dt\| ≤ 60 ms` | `sync[]` | 视觉事件与 cue 的时间差 |
| **画面长时间静止** | 连续 6 s 内最活跃 8×8 块 0.5 s 漂移 ≤ 1.5 级灰度 | `warnings[]` | warning：可能卡帧，也可能是刻意定版 |
| 音画同步"没在查" | `sync[]` 为空且 `sync_info.judged == 0` | warning（默认）/ error（开 `QA_REQUIRE_SYNC=1`） | **最危险的一条：看起来零超差，其实一条都没查** |
| 时长复核 | 与预期差 ≤ 0.5 s | `errors[]` | error：独立于容器层再查一次 |
| 响度曲线 | 无 >12 s 低于 -40 LUFS | `loudness[]` | warning：长段无声 |

> **画面静止的判据是"最活跃 8×8 块在 0.5 s 内的漂移"**，详见 `references/frame-qa.md` §2.4b。
> 不要用"全帧平均亮度 3 s 波动 < 2%"这类公式：全帧均值对逐字入场/数字滚动这类局部动画
> 天生不敏感（自带示例片会误报 4 段）。

### 单帧闪烁的判据（照抄实测有效的做法）

```
d[t] = | F[t] - (F[t-1] + F[t+1]) / 2 |        # 逐帧、160×90 灰度、8×8 分块取最大块均值
异常 = d[t] > 阈值 且 d[t-1] 与 d[t+1] 都低于阈值（孤立性）
```

**必须排除"设计好的重击"**：闪白/震屏/冲击环会写进 `events`（web 引擎由页面导出，
PIL 引擎写进 `cues.json`），检出的时刻与之相差 < 0.2 s 就不算缺陷。

实测参考值（同一部片子）：正常运动画面 d ≤ 6，真正的单帧 bug d = 10–15。
**没有量过一次的片子，不要凭感觉定阈值。**

### 常见的三类单帧 bug（都踩过）

1. **位移/推力没归零**：某段结束时还挂着 0.8 个单位位移，下一帧跳回原位——所有粒子多画一帧径向拖尾。
   → 让推力在结束前 0.05 s 平滑归零。
2. **粒子贴镜头过曝**：按面积补偿亮度时，离镜头 1 个单位的粒子被放大 70 倍。
   → 补偿封顶 + 3.5 单位内淡出。
3. **转速/相位突变**：换参照轴、改转速后一帧跳一截。
   → 连续积分而非查表；平滑半径与突跳分量分离。

## G8 页面层门禁（仅 `--engine web`）

```bash
python webengine.py textqa ./web/index.html --step 0.2
```

| 判据 | 阈值 | 说明 |
|---|---|---|
| 文字重叠 | 0 处（重叠面积比 ≥ 8% 才算） | 卡片/标注/HUD 互相压住 |
| 出画 | 0 处 | 包围盒超出 1920×1080 边界 6 px |
| 一闪而过 | 0 处 | 存在时长 < 0.6 s 的文字没人读得完 |
| 从没露面 | 0 处 | 有文字内容的元素全片没显示过（改名后最容易静默失效） |

**"元素存在性"是分水岭**：画面"能出图"时，最难发现的是"该有但没有"。
字段改名（`act.t0` → `act.start`）后，全片十幕淡入与图名框静默失效、零报错。
页面层的 `never` 列表就是专门抓这个的。

## 三层质检合起来的交付话术

交付时不要写"已完成"，写实测值：

```
容器：1920x1080 / 30 fps / h264+aac / 48 kHz / 时长 389.02 s
信号：-16.3 LUFS / 真峰 -1.2 dBTP / 锐度比 0.94 / 黑帧 0 / 字幕 86 条 = 剧本 86 句
时间：单帧闪烁 0 / 画面空窗 0 / 音画同步最大偏差 38 ms
页面：文字重叠 0 / 出画 0 / 一闪而过 0 / 从没露面 0
自检：python selfcheck.py -> PASS 70 / FAIL 0 / SKIP 0
```
