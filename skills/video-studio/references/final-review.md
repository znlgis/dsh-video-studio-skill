# 独立终检（final review）

> 制作者对自己的产出有确认偏差。所有自查（selfcheck / 门禁 / 签核）都在同一个上下文里完成，
> 最容易漏的恰恰是「我以为我做了」的那部分。独立终检就是把评审这件事**外包给一个不参与制作、
> 看不到辩解的人**——通常是一个干净上下文的 subagent。

## 一、谁评、评什么

- **评审者**：干净上下文。不读制作过程、不看修改历史、不接收"我们原本想…"这类说明。
- **评审对象**：`work/review/` 整个目录 + 成片 MP4。评审者只看这些。
- **评审输入**（都已在包里，或按包里的路径去取）：
  - `work/review/PACKET.md`：这一版是什么 + 门禁现状 + 逐条清单 + 输出格式；
  - `work/review/frames/`：每段 enter / settle 各一张（帧号来自 `timeline.review`，不是随手抽的）；
  - `work/review/_sheet.png`：联系表，一眼看完全片节奏；
  - `out/QC-REPORT.md`：机器生成的交付凭据（响度、真峰、锐度比、门禁矩阵）；
  - `work/gates.json`：门禁原始条目（`skipped` 必须逐条说明为什么没跑）；
  - 项目侧输入：`FACTS.md`（数字出处）、`film.json`、素材清单的许可字段。

包里没有的输入，**评审判「无法验证」，不许自己猜制作基准**。

## 二、怎么出包

```bash
python <SKILL_DIR>/scripts/render.py --script film.json --work work --out out/film.mp4 --stage review
```

- 只读成片与账本：不重渲、不改任何既有产物，可以随时重跑；
- 成片不存在直接报错（不降级重渲——评审必须对着交付的那一版）；
- 帧抽失败逐条列出，缺证据的段在 R1 门禁里记 fail。

## 三、评审者的输出格式（必须照抄）

```text
结论：通过 / 不通过（二选一，不许写「基本可以」）
阻断项（必须修的）：
  - [R3] 第 4 段落定只停了 0.4s · 证据 work/review/frames/03_l04_settle_0.00s.png
建议项（可改可不改的）：
  - [V3] 全片 5 个色相，超出 4 个的上限，但主色只有两种，建议确认是否接受
无法验证的项：
  - [D1] FACTS.md 不存在，上屏数字的出处无法核对
```

- 每条 `✓ / ✗ / 无法验证` 都要落到**帧号或文件名**；
- **不许**写「整体感觉不错」「画面很有质感」这类没有证据的话；
- **不许**把没查的写成通过（`skipped` 门禁 = 没查）；
- 与制作方给的理由冲突时，报告冲突本身，不替制作方挑一个当真相。

## 四、清单从哪来

清单不写死在本文件里，由 `scripts/reviewpacket.py` 的 `REVIEW_GROUPS` 生成，分七组：

| 组 | 主题 | 典型条目 |
|---|---|---|
| P | 产品与叙事 | 信息讲清楚了吗、有没有说两遍、有没有夸大 |
| B | 分镜与时长 | 每句都有画面、落定是否留得住、有没有太赶 |
| V | 视觉 | 是否符合 design.json、字幕安全区、色相数、白闪/空窗 |
| S | 声音 | 配乐盖人声、音效钉帧、该响的地方、响度真峰 |
| D | 数据与素材安全 | 数字出处、敏感信息、素材许可 |
| A | 音画同步 | cues 与画面对拍、音轨偏移是否实测过 |
| Q | 交付与可复现 | skipped 是否解释、签核是否仍有效、重跑命令 |

为什么放在代码里：**清单最容易腐化的方式是越改越短，而没人发现**。
写成函数后 `ci_check` 可以直接断言「组数 = 7、条目数 ≥ 22」，删条目会立刻红。

## 五、评审之后

1. 阻断项逐条修，再重出评审包（`--stage review` 幂等，帧会按新帧号重抽）；
2. 修完之后**必须重跑一遍评审**——改了画面不重评，等于拿旧结论交付新片；
3. 评审结论与 QC-REPORT 一起交付；`--stage accept --gate release` 是人工签核，和独立评审是两道闸，不能互相替代。

## 六、和签核的区别

| | 独立终检（本文件） | 人工签核（`--stage accept`） |
|---|---|---|
| 谁做 | 干净上下文评审者 | 用户/交付负责人 |
| 看什么 | 成片 + 逐镜帧 + 门禁 + 清单 | 一遍成片 + 报告 |
| 绑什么 | 内容指纹（review 包） | 内容指纹（signoff.json，改了内容自动失效） |
| 不能替代 | 人工签核（要人负责） | 独立评审（要独立视角） |
